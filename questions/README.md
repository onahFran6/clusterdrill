# Question folder shape

Every question is one folder under a topic directory:
`questions/<topic>/qNNN-slug/`. Copy `questions/_template/` to start a new one.

## `domains.fragment.yaml` (one per topic, not per question)

Each topic directory owns exactly one `domains.fragment.yaml`. This is the
only file multiple questions in a topic share, so add your question's entry
to it - never touch another topic's fragment, and never hand-edit
`.generated/domains.yaml` (that's rebuilt by `lib/load-domains.sh`).

```yaml
topic: <topic-dir-name>          # must match the directory name exactly
questions:
  - id: qNNN-slug                 # must match the question's folder name
    domain: "Application Environment, Configuration and Security"  # one of the 5 CNCF domains
    difficulty: easy | medium | hard
    resource_kinds: [ConfigMap, Pod]   # k8s Kinds this question touches - feeds lib/generate_diagram.py
    points: 5                     # relative weight within the topic, not exam points
```

## Question folder contents

| File | Purpose |
| --- | --- |
| `QUESTION.md` | The task as the candidate sees it: title, CNCF domain + points, the task description, and a **Hint** that is a *search term* against kubernetes.io/docs - never a direct link. |
| `setup.sh` | Idempotent. Creates/resets namespace `qNNN` and seeds any broken/partial resources the task requires. Every object it creates - namespaced or cluster-scoped - gets the label `clusterdrill-question=qNNN`. Safe to re-run without accumulating duplicates. A `# TODO:` comment inside `setup.sh` marks the gap the candidate is meant to close - it is the exercise itself, not an engineering to-do, and must not be "fixed" or removed. |
| `check.sh` | Sources `lib/grading.sh`. Uses `resource_exists` / `kget` / `check_criterion` to test **only live cluster state** - never a client-supplied "done" flag. Ends with `print_score`. **Never `set -e`** - a failed criterion returning non-zero is normal, not a script error; `set -e` would abort before later criteria run and before `print_score` prints, which looks like a false 0. Use `set -uo pipefail` instead. |
| `ANSWER.md` | The reference solution: exact commands/manifests, in a single fenced ```` ```sh ```` (or ```` ```bash ````) code block - `lib/verify-question.sh` extracts and runs that fence verbatim, so it must be the literal commands, not prose. Also include the direct kubernetes.io doc link (unlike the Hint, this file is allowed to link straight to the answer). |
| `diagram.mmd` | A Mermaid diagram fragment, generated by `lib/generate_diagram.py` from `resource_kinds` above - don't hand-author it for individual questions. |

## The one hard gate

A question is not "in the bank" until it passes:

```sh
lib/verify-question.sh questions/<topic>/qNNN-slug
```

That script asserts: unsolved state scores 0, the reference answer
in `ANSWER.md` scores full marks, and a second reset leaves zero objects
behind matching `-l clusterdrill-question=qNNN` anywhere in the cluster
(any namespace, cluster-scoped included).
